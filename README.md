Prismheart is an original neon arena-defense game that runs entirely from static files in a desktop browser. Pilot a warden around a living crystal heart, survive ten escalating waves of geometric hunters, pick an upgrade card between waves, and destroy the Null Choir before it shatters the heart — or your hull.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, aim and fire with the mouse, dash with Shift or right-click, and pulse with Space.
